# Repo Notes

This repository is the shared Dingxi brand-image knowledge layer.

Before making changes, also read:

- `docs/PROJECT_MEMORY.md`
- `docs/RUNBOOK.md`
- `docs/OPERATIONS_LOG.md`
- `README.md`
- `docs/dingxi-brand-image-sop.md`
- `skills/dingxi-brand-image/SKILL.md`

## Scope

Keep here:

- cross-project Dingxi brand-image SOPs
- reusable prompt patterns
- brand reference asset documentation
- Codex skill source for Dingxi brand image work

Do not move browser launch/session logic here; that belongs in `cbs-workflows` or
`browser-automation-workflow`.

Do not move deck-specific exports or one-off production artifacts here unless
they are being kept as a documented reusable example.

## Public Repo Safety

Do not commit official Dingxi crest files, mascot image files, scan outputs,
contact sheets, source Illustrator/PSD/PDF brand assets, or temporary generated
images. Keep those in the school internal network source folder.

This repository may document the internal AI work-assets folder path and the
expected filenames, but should only publish workflow text, prompts, skill source,
and safety rules.
