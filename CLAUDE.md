# CLAUDE.md

This repository uses repo-local memory. Before making changes, read the project memory documents and brand-image workflow contract.

## Required startup steps

1. Read `AGENTS.md`.
2. Read `README.md`.
3. Read `docs/PROJECT_MEMORY.md`.
4. Read `docs/RUNBOOK.md`.
5. Read `docs/OPERATIONS_LOG.md` when recent work may matter.
6. Read `docs/dingxi-brand-image-sop.md`.
7. Read `skills/dingxi-brand-image/SKILL.md`.
8. Read `skills/dingxi-brand-image/references/prompt-patterns.md` when drafting reusable prompts.
9. Treat repo documents as the source of truth over Nowledge Memory, Working Memory, or raw Threads.
10. Do not overwrite unrelated user changes.

## Safety rules

- This repo contains workflow text, prompts, skill source, and safety rules only. It must not contain official Dingxi crest files, mascot image files, source Illustrator/PSD/PDF brand assets, contact sheets, scan outputs, temporary generated images, or one-off production exports.
- Official brand image files must stay in the school internal network source folder or local working asset folders, not in this public repo.
- Do not copy the whole internal brand folder. Copy only the needed files for a specific authorized workflow.
- Do not generate, imitate, redraw, or publish official crest-like marks unless the selected mode and QA rules allow it.
- Keep browser launch/session logic in `cbs-workflows` or `browser-automation-workflow`, not here.
- Keep deck-specific exports in `slidecraft-lab` or the owning presentation repo, not here.

## Memory update policy

Update memory docs after significant changes to brand-image SOP decisions, prompt patterns, skill trigger/contract, crest strategy, mascot integrity rules, internal asset routing, or repo boundaries with browser automation and deck projects.

Security, privacy, account, permission, organization, and cross-project rules require explicit user confirmation before being written as memory.
